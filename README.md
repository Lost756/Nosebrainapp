Nosebrain Judge - это мобильное приложение для Android, которое позволяет судить соревнования по ноузворку (nosework) в автономном режиме.

Приложение включает в себя всё необходимое для организации и проведения соревнований.
Основные возможности:
1)Создание соревнований
2)Создание участников
3)Создание категорий
4)Автономное проведение соревнования
5)Сохранение результов
6)Синхронизация с локальным веб-сервером

Стек технологий:
1)Язык:Java
2)Минимальная версия Android:7.0 (API level 24)
3)Локальная база данных:Room (SQLite)
4)UI компоненты:Material Design Components, ConstraintLayout, RecyclerView

Для сборки и запуска проекта вам понадобится Android Studio.
